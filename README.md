# 🎮 MCGG Predictor

<p align="center">
  **Android App — Manual Opponent Analysis & Probability Prediction**
</p>

Aplikasi Android untuk membantu menganalisis riwayat lawan di MCGG melalui input manual dan menampilkan estimasi probabilitas berdasarkan data yang dimasukkan.

## ✨ Features

* 📊 **Probability Prediction** — Estimasi probabilitas berdasarkan riwayat yang dimasukkan.
* 📝 **Manual History Input** — Tambahkan dan kelola data lawan secara manual.
* 📱 **Android Friendly** — Dirancang untuk digunakan di perangkat Android.
* ⚡ **Simple Interface** — Antarmuka sederhana dan mudah digunakan.
* 🔍 **Opponent Analysis** — Membantu membaca pola dari data pertandingan sebelumnya.

1. Download file APK dari halaman Releases.
2. Buka file APK di perangkat Android.
3. Izinkan instalasi aplikasi dari sumber tersebut jika diperlukan.
4. Selesaikan instalasi dan buka aplikasi.

## 🛠️ Built With

* Android
* Java/Kotlin — sesuai bahasa yang digunakan project
* Gradle

## ⚠️ Disclaimer

Aplikasi ini merupakan alat analisis berbasis input manual. Hasil prediksi berupa estimasi probabilitas, bukan jaminan hasil pertandingan. Akurasi bergantung pada kualitas dan jumlah data yang dimasukkan.

Aplikasi ini tidak menjamin kemenangan dan tidak mengklaim memiliki akses ke sistem internal game.
